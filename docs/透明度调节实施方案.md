# 自定义壁纸「透明度调节」实施方案

> 交付对象：Flash（下次执行）。本方案由 Claude 编写于 2026-10-27，基于当前 Phase 1.5 代码结构。
> **状态更新（2026-10-30）：已由 Claude 按本方案实现并进入 v1.3（用户指示继续推进），本文档保留为设计记录。**
> 需求来源：用户（参考其六级单词 App 的成熟做法——照片以可调透明度融入主题渐变，任意照片保证文字可读）。
> 预计改动量：约 40 行，涉及 3 个文件，无数据迁移风险。

## 目标效果

- 仅对「自定义图片壁纸」生效：照片不再 100% 实色铺满，而是以 30%~100% 的不透明度叠在主题渐变色之上；
- 透明度调低时，照片自然融入暖橙主题色，卡片文字对比度自动提升；
- 预设渐变壁纸不显示滑杆（它们本身就是主题色）；
- 设置持久化，重启后保持；不重新编码图片（纯 CSS，零画质损失，不增加存储占用）。

## 实现步骤（按顺序做）

### 第 1 步：数据类型加字段 —— `src/data/types.ts`

```ts
export interface Wallpaper {
  type: 'preset' | 'image'
  value: string
  /** 图片壁纸的不透明度 0.3~1，缺省 1（完全实色） */
  opacity?: number
}
```

### 第 2 步：读取兼容 —— `src/storage/index.ts`

`migrate()` 里 settings 是整对象透传（`d.settings ?? seed.settings`），`opacity` 缺省即为 `undefined` → 视作 1，**无需改迁移代码**。只需确认：老数据没有该字段时不报错（TypeScript 可选字段天然满足）。

### 第 3 步：双层渲染 —— `src/App.tsx` 的 `Shell` 组件

现在图片壁纸的渲染是：

```tsx
<div className="fixed inset-0 -z-10" style={wallpaperStyle(wp, tab)} />
{wp.type === 'image' && <div className="fixed inset-0 -z-10 bg-white/35" />}
```

改成三层：底层永远是主题渐变，图片层用 `opacity` 淡入，最上保留现有浅白柔化层：

```tsx
{/* 底层：主题渐变（图片模式下取用户壁纸同款预设色系，preset 模式即壁纸本身） */}
<div className="fixed inset-0 -z-10" style={wallpaperStyle(wp, tab)} />
{/* 图片层：可调透明度 */}
{wp.type === 'image' && (
  <div
    className="fixed inset-0 -z-10 bg-cover bg-center transition-opacity duration-300"
    style={{ backgroundImage: `url(${wp.value})`, opacity: wp.opacity ?? 1 }}
  />
)}
{/* 柔化层：透明度低时可省略，>=0.7 时保留，避免照片太抢 */}
{wp.type === 'image' && (wp.opacity ?? 1) >= 0.7 && <div className="fixed inset-0 -z-10 bg-white/25" />}
```

同时把 `wallpaperStyle()` 中 image 分支的 `backgroundImage` 输出删掉（改由图片层负责），preset 分支保持不变（渐变角度偏移逻辑 today+0/stats+40/me-35 不动）。

### 第 4 步：滑杆 UI —— `src/pages/MePage.tsx` 壁纸卡片

在「当前：xxx」一行之前插入（仅 `wp.type === 'image'` 时渲染）：

```tsx
{wp.type === 'image' && (
  <div className="mt-3">
    <div className="flex items-center justify-between text-[11px] text-slate-400">
      <span>照片浓度</span>
      <span>{Math.round((wp.opacity ?? 1) * 100)}%</span>
    </div>
    <input
      type="range"
      min={30}
      max={100}
      step={5}
      value={Math.round((wp.opacity ?? 1) * 100)}
      onChange={(e) => void setWallpaper({ ...wp, opacity: Number(e.target.value) / 100 })}
      className="mt-1 w-full accent-orange-500"
      aria-label="照片浓度"
    />
  </div>
)}
```

说明：
- `setWallpaper` 已存在，直接传整个 `wp` 加 `opacity` 即可；每次 onChange 都会触发一次 localStorage 写入。数据量小（几 KB JSON + 一张图 dataURL），实测无卡顿，可不做防抖；若不放心可自行加 300ms 防抖（用 `useRef` + `setTimeout`）。
- range 的 `min=30` 即下限 30%，对应六级单词 App 的 30%~100% 区间。

### 第 5 步：恢复默认

滑杆旁或下方加一个小按钮（可选，建议加）：

```tsx
{(wp.opacity ?? 1) !== 1 && (
  <button onClick={() => void setWallpaper({ ...wp, opacity: 1 })} className="text-[11px] text-orange-500">
    恢复 100%
  </button>
)}
```

## 验收清单

1. 上传一张照片壁纸，默认 100% 时与现状一致（完全实色）；
2. 拖到 50%：照片明显变淡、透出暖橙底色；拖到 30%：照片只是隐约可见；
3. 滑杆调整过程中卡片文字始终清晰可读（白/85 卡片 + 柔化层保证）；
4. 切到「统计」「我的」页再回来，透明度保持；
5. 刷新页面 / 杀掉重开，透明度保持（localStorage）；
6. 切回任一预设渐变壁纸：滑杆消失，显示恢复正常；
7. 再切回图片壁纸：透明度值还在。

## 已知边界（不用处理）

- 图片本体不做任何重编码，透明度纯 CSS，不占额外存储；
- 透明度不参与打卡彩带 / 徽章动效的层级（confetti z-index 200，永远在最上）；
- 深色照片在低透明度下会偏暗，属预期效果（底色是暖橙渐变会自动提亮）。
